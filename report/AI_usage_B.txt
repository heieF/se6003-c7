Tool
----
Claude (Anthropic), model Claude Opus 5.5, used through the claude.ai app,
12-13 November 2026. The assistant could run Python in a cloud workspace

What the AI tool did
--------------------
1. Code. Wrote layer1.py (row_from_witness, merge_neurons,
   row_from_witness_coord), signs.py (fix_signs, fix_signs_lstsq),
   refine.py (refine_layer1) and the helper bmetrics.py, following the
   interfaces in the group plan (Appendix B) and Carlini et al., CRYPTO 2020,
   Sec. 4.2, 4.3.1, 5.1 and 5.2.
2. Tests. Wrote tests/test_layer1.py, tests/test_signs.py,
   tests/test_refine.py and tests/test_b_pipeline.py.
3. Experiments. Wrote experiments/b_rows.py, b_signs.py, b_refine.py and
   b_style.py, ran them, and produced results/b_*.csv, figures/B/*.pdf
   and tables/B/*.tex.
4. Method ideas proposed by the AI tool:
   - the least-squares sign test based on ReLU(-z) = ReLU(z) - z (Sec. 3.3);
   - the slope-jump consistency check that detects finite-difference probes
     crossing the witness's own hyperplane (Sec. 3.2);
   - locating the kink by intersecting two lines instead of bisection
     (Sec. 3.5).
5. Report. Drafted Sections 3.2, 3.3 and 3.5, Algorithm 2, Proposition 2
   and its proof, Fig. B1, Fig. B2, Table B1, the row-method comparison
   table, and refs_B.bib (entry typed in DBLP key format, not exported
   from dblp.org).
6. Debugging and review. Found and fixed a bug in row_from_witness (wrong
   rows when the search line is nearly parallel to the hyperplane), and an
   accidental reformatting of the frozen common.py (restored).
7. Tooling. Committed and pushed the code to GitHub and uploaded the report
   sections to Overleaf on my instruction.
